# 🎨 学习的魔法之旅 — 小学生 40 种学习方法大全

一个专为小学生设计的全屏幻灯片式学习网站，图文并茂、分五大类别系统介绍 **40 种高效学习方法**。

> 🌐 **[在线浏览 →](https://jianghao.wang/little-learning-magic/)**

## ✨ 特色

- 🖥️ **全屏幻灯片模式** — 每种方法占满整个视口，图文铺满，大字清晰
- 🗂️ **五大分类体系** — 时间管理 / 记忆强化 / 深度理解 / 互动激励 / 情绪习惯
- 🎨 **温暖绘本风格** — 马卡龙色系 + 圆体字 + 浮动装饰元素
- 📊 **AI 信息图插图** — 40 张 GPT-Image-2 生成的 4:3 横版教育信息图，以女小学生为主角
- 🧭 **三层导航系统** — 分类总览卡片 → 分类标题页 → 动态顶部导航条
- ⌨️ **键盘/触屏翻页** — 方向键 / PageUp/PageDown / 触屏滑动
- 📱 **响应式设计** — 桌面端图片左（60%）文字右（40%），移动端自动竖排

## 🚀 使用方法

```bash
git clone https://github.com/Jianghao/little-learning-magic.git
cd little-learning-magic
# 直接用浏览器打开 index.html
# 或用任意静态服务器托管
npx serve .
```

## 📁 项目结构

```
├── index.html          # 主网站（33 个全屏 slide，内嵌 CSS + JS）
├── README.md           # 项目说明
└── images/             # 24 张 AI 生成的信息图（4:3, 2048×1536）
    ├── 01-preview-review.png
```

## 🛠️ 技术栈

- **纯 HTML/CSS/JS** — 零依赖，单文件即用
- **CSS Scroll Snap** — 原生幻灯片滚动效果
- **Intersection Observer** — 智能检测当前页
- **Google Fonts** — ZCOOL KuaiLe（标题）+ Noto Sans SC（正文）
- **GPT-Image-2** — 所有信息图由 AI 生成
