# 🎨 学习的魔法之旅 — 小学生十大学习方法

一个专为小学生设计的全屏幻灯片式学习网站，图文并茂地介绍 **10 种高效学习方法**。

## ✨ 特色

- 🖥️ **全屏幻灯片模式** — 每种方法占满整个视口，图文铺满，大字清晰
- 🎨 **温暖绘本风格** — 马卡龙色系 + 圆体字 + 浮动装饰元素
- 📊 **信息图插图** — 10 张 AI 生成的 4:3 横版教育信息图
- ⌨️ **键盘/触屏翻页** — 方向键 / PageUp/PageDown / 触屏滑动
- 📱 **响应式设计** — 桌面端图片左文字右，移动端自动竖排
- 🔝 **顶部导航条** — 方法详情页顶部列出全部 10 种方法，一键跳转

## 📋 十大学习方法

| # | 方法 | 一句话 |
|---|------|--------|
| 01 | 🔍 预习与复习法 | 形成学习闭环，知识牢牢扎根 |
| 02 | 🍅 番茄专注法 | 25分钟专注 + 5分钟休息 |
| 03 | 👨‍🏫 费曼小老师法 | 把知识讲给别人听才是真学会 |
| 04 | 🗺️ 思维导图法 | 用画图的方式整理知识 |
| 05 | 💎 错题宝藏法 | 每道错题都是进步的宝石 |
| 06 | 📅 间隔记忆法 | 像浇花一样定时复习 |
| 07 | ❓ 提问学习法 | 带着问题去学习 |
| 08 | 🪜 目标分解法 | 大目标拆成小台阶 |
| 09 | 🧩 联想记忆法 | 编故事让记忆变有趣 |
| 10 | ✅ 自我检测法 | 学完后考考自己 |

## 🚀 使用方法

1. 克隆仓库：`git clone https://github.com/wangjh/little-learning-magic.git`
2. 直接用浏览器打开 `index.html`
3. 或用任意静态服务器托管（如 `npx serve .`）

## 📁 项目结构

```
├── index.html          # 主网站（单文件，内嵌 CSS + JS）
└── images/             # 10 张 AI 生成的信息图
    ├── 01-preview-review.png
    ├── 02-pomodoro-focus.png
    ├── ...
    └── 10-self-testing.png
```

## 🛠️ 技术栈

- 纯 HTML/CSS/JS，零依赖
- CSS Scroll Snap 实现幻灯片效果
- Intersection Observer 检测当前页
- Google Fonts (ZCOOL KuaiLe + Noto Sans SC)
